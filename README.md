# Python Chess Engine

A chess engine written from scratch in Python, built as a learning project using the [Chess Programming Wiki](https://www.chessprogramming.org/) as the main reference.

## Requirements

- Python 3.10+

## Installation

**Windows (PowerShell)**

```powershell
git clone https://github.com/Raph3141/python-chess-engine.git
cd python-chess-engine
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**macOS / Linux**

```bash
git clone https://github.com/Raph3141/python-chess-engine.git
cd python-chess-engine
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Usage

```bash
python main.py
```
